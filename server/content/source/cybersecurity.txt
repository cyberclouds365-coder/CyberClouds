

Road Map
1). Foundation / Basics: Introduction to IT, Operating Systems (Linux and Windows), and scripting/coding (like Python).


2). Computer Networking: TCP/IP models, routing, switching, and core protocols (DNS, HTTP, HTTPS).


3). Network Security & Firewalls: Packet analysis, firewalls, VPNs, and Intrusion Detection/Prevention Systems (IDS/IPS).


4). Cryptography: Symmetric/asymmetric encryption, public key infrastructure (PKI), and hashing.


5). Identity and Access Management (IAM): Multi-factor authentication (MFA), Single Sign-On (SSO), and role-based access control.


6). Web Application Security: Understanding vulnerabilities like the OWASP Top 10 (SQL injection, XSS) and secure coding.


7). Ethical Hacking & Penetration Testing: Vulnerability assessment, reconnaissance, exploitation tools (like Metasploit and Nmap), and reporting.


8). Security Operations (SOC) & SIEM: Log analysis, event monitoring, threat hunting, and using platforms like Splunk or ELK.



9). Incident Response & Digital Forensics: Handling security breaches, evidence gathering, malware analysis, and disaster recovery.



10). Cloud Security: Securing cloud environments (AWS, Azure, GCP), IAM misconfigurations, and container security.

UDP vs TCP differences
    • TCP (Connection-Oriented & Reliable): It establishes that 3-way handshake first. If a packet drops, TCP retransmits only the missing piece until everything arrives 100% perfectly.
    • UDP (Connectionless & Unreliable): No handshake, no feedback. It just fires packets like a machine gun. If a packet drops, it's gone forever. But because there is no checking, it is blazing fast.
