Federation Trust
    • Metadata Exchange:
      Think of metadata as a digital handshake between Keycloak and an application (like Google Workspace or AWS). Both sides exchange a simple setup file containing their URLs and public keys so they know how to talk to each other securely.
    • Certificate Rotation:
      The digital keys used to sign SSO messages expire over time for security reasons. Certificate rotation is simply updating these keys with new ones every 1–2 years so the trust stays active and secure.


Common SSO Attack Vectors
      Token Replay Attack:
    • An attacker steals a valid, active login token (like a concert ticket) and presents it to the server. Because the token itself is legitimate, the system lets the attacker in without asking for a password or MFA. 
    • (use the sort life of JWT to reduce this attack)
    • Realm Settings $\rightarrow$ Set Token Lifespan to 5 mins + Enable Revoke Refresh Token.
      
      XML Signature Wrapping (XSW) in SAML:
    • SAML login messages use XML formatted text. In an XSW attack, the attacker takes a valid, signed SAML message, moves the real signed part to the bottom, and inserts a fake admin user part at the top. The server verifies the real signature at the bottom but logs the user in using the fake identity at the top.
    • (used more validation in this to reduce this things)
    • SAML Client Settings $\rightarrow$ Turn ON Sign Assertions and Sign Documents.
